# 吟游诗人完美轴·完全控制版 0.3.0

> ⚠️ 任何第三方插件都有可能导致账号处罚或封号，后果由使用者自行承担。开别怕，怕别开。

这是独立于影子版的自动执行版本。必须手动启动；运行后会读取游戏状态并实际释放技能。

0.3.0 的默认循环依据 NGA《7.0 吟游诗人起手爆发，循环技巧》实现：
https://bbs.nga.cn/read.php?tid=41932841

## NGA 攻略完美轴

- `2.47 / 2.48 GCD` 自动采用 `3-3-12`：43秒旅神、43秒贤者、34秒军神；游戏量谱剩余 `2 / 2 / 11秒` 时切歌。
- `2.49 / 2.50 GCD` 自动采用 `3-6-9`：43秒旅神、40秒贤者、37秒军神；游戏量谱剩余 `2 / 5 / 8秒` 时切歌。
- 起手先上狂风蚀箭，再开旅神与九天，然后补烈毒咬箭；团辅按战斗之声、光明神、猛者的顺序错开，并让团辅在后半 GCD 插入以争取 9/9。
- 九天连箭以真实15秒 CD 为最高能力技优先级；3层诗音，或2层且九天即将转好时，先打完美音调避免溢出。
- 纷乱箭后优先纷乱辉煌箭与共鸣箭；80点以上魂音按爆发窗口使用绝峰箭并衔接爆破箭；光明神返场在团辅内释放。
- 猛者末段会比较双 DoT 剩余秒数和未结算 tick 威力，再决定是否用伶牙俐齿截毒。普通刷新仍按实际 DoT 与 GCD 动态窗口判断。
- 攻略只提供目标顺序；最终执行时间始终以游戏读取到的真实 CD、状态、诗音、魂音、DoT 和 Boss 是否可选为准。

## 执行规则

- 仅支持吟游诗人，倒地、切换职业或战斗结束时立即停止。
- 每个实际结算的 GCD 开启一个新周期；每周期最多插入 2 个能力技，绝不会尝试第三个。
- 两次已接受动作之间至少间隔 0.70 秒，并同时检查动画锁和游戏动作队列。
- 下一个 GCD 进入排队窗口后优先 GCD，不再继续插能力技。
- NGA攻略自动轴、手动3-3-12、手动3-6-9与Custom自定义歌轴均保留。
- GCD 与歌轴相互独立；技能使用游戏读取到的真实 CD、歌曲量谱、诗音和触发状态。
- 双 DoT 按每3秒一次估算剩余 tick 与尚未结算威力，并参与刷新决策。
- 自动读取普通热键栏的实际键位用于显示，不要求在插件里重新绑定。
- 读取角色的 `EffectiveLevel`：同步到50级及以下时自动启用低等级循环，不需要另做配置。
- 50级使用强力射击、直线射击、毒咬箭与风蚀箭；没有旅神、完美音调、九天连箭和伶牙俐齿。
- 50级歌曲只循环贤者与军神，两首都未转好时保留空歌期，不会尝试尚未学习的技能。
- 点击控制状态窗右上角 `X` 会立即停止自动执行并隐藏窗口。

## Boss 上天与丢失索敌

目标消失、死亡或暂时不可选时，执行器进入停火状态，不发送任何动作，但歌曲与真实 CD 继续自然计时。

如果同一个目标对象重新变为可选，插件会自动沿用它，并废弃上天前已经错过的动作，按复现时的真实 CD、歌曲、诗音与目标 DoT 重新规划下一轮。插件不会为了重新索敌擅自选择场上的其他小怪。如果 Boss 以全新的对象 ID 出现，需要玩家选中一次。

## 命令

- `/brdcontrol start`：手动启动完全控制并等待进入战斗。
- `/brdcontrol stop`：立即停止所有自动执行。
- `/brdcontrol reset`：放弃当前执行周期并按实时状态重新规划。
- `/brdcontrol config`：打开设置与循环编辑器。
- `/brdcontrol overlay`：显示或隐藏控制状态窗。

## 歌轴

- `NGA攻略自动轴`：2.47/2.48自动选3-3-12；2.49/2.50自动选3-6-9。
- `Standard 3-3-12`：固定43旅、43贤、34军。
- `Advanced 3-6-9`：固定43旅、40贤、37军。
- `Custom`：分别修改旅神、贤者和军神的切歌剩余秒数。

DoT tick 使用服务器统一节拍，所以“剩余秒数 ÷ 3”属于收益估算，不承诺精确命中下一次服务器 tick 相位。
