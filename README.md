# 吟游诗人完美轴 · 半自动版

当前版本：**1.1.1**

> **任何第三方插件都有可能导致封号，后果自负。开别怕，怕别开。**

这是一个给吟游诗人用的 Dalamud 插件。你负责选目标、走位和处理机制，它帮你打输出循环、切歌、开进攻团辅，以及使用事先选好的药和食物。

名字叫“完美轴”，不等于能保证满分，更不代表用了不会出问题。目前已通过本地编译和自动测试，**新版还没有完成游戏内实测**。建议先开“仅影子观察”，看看它给的技能建议是否正常，再决定是否开启自动输出。

## 它会帮你做什么

- 根据技能冷却、诗心、量谱和双 DoT 的剩余时间安排输出。DoT 是毒和风的持续伤害，不会只算上箭时的那一下。
- 自动使用战斗之声、光明神的最终乐章、猛者强击和纷乱箭等进攻技能。减伤、增治疗、解状态、打断和位移仍然由你自己按。
- 两个 GCD 之间最多插两个能力技；军神满层时按单插处理。不会为了多塞技能硬补第三插。
- 有多个目标时，根据当前选中目标的位置比较单体和群攻的收益。它不会帮你换目标，也不会替你走到怪群中间。
- 等级同步后使用当前等级能学会的技能。例如绝神兵是 70 级，用的是失血箭、连珠箭，不会去按 100 级才完整拥有的那套技能。
- 可以选择通用 3-3-12、进阶 3-6-9、上天恢复、绝神兵或自定义方案。GCD 速度也可以自己填。

## 怎么开始用

先看[安装与使用说明](安装与测试.md)。装好后：

1. 输入 `/brdcontrol config` 打开设置，选适合当前副本的方案。不是打绝神兵，就不用选绝神兵方案。
2. 在“自动药食”里分别选好药和食物，注意 HQ、NQ 是分开的。不选就不吃，也不会自动买或换成别的品种。
3. 先用“仅影子观察”看建议。这个模式不会放技能，也不会消耗药食。
4. 确认设置后退出影子模式，选中目标，手动启动，再正常开怪。插件不会主动替你拉怪。

点停止或用 `/brdcontrol stop` 可以停下；关闭控制窗口的 X 也会停止。单独隐藏状态提示窗不等于停止。一发已经交给游戏排队的技能，停止后仍可能打出来。

团灭或副本结束后需要重新启动。中途点“重新规划”不会把这把的用药计时清零。

## 药和食物怎么吃

**1.1.1 把第一瓶药提前了。** 检测到进战后，如果所选药可用、当前适合爆发，会先吃药，看到药效并等用药动作结束，再开始自动输出和团辅。不再等打完第一个 GCD 才插药。

这不是倒计时预吃药。你手动打出去的开怪技能，可能比药效更早；先吃药也可能让第一发自动 GCD 稍晚一点。已有药效时不会重复吃。

第二瓶默认安排在开怪后 **4:30**，可以自己改。药没转好、Boss 正在上天或暂时不适合爆发，就往后等；4:30 不是所有副本都最合适的用药点。第三瓶起，最早在上次用药 270 秒后检查，实际冷却仍以游戏为准。

食物只在插件已启动、自己脱战且需要续吃时使用。如果身上还有另一种食物的效果，会先保留，不强行覆盖。只查看四个随身背包，不会去雇员或陆行鸟鞍囊里找东西。

如果已经发出用药请求，却一直确认不了是否成功，插件会停止。请先看背包和身上的增益，不要反复启动来试药。具体处理见[开怪首药说明](1.1.1开怪首药说明.md)。

## 绝神兵方案有什么不同

主要是尽量避开“刚开完爆发，Boss 就上天”的情况。

风神、火神、土神和神兵会分开判断。土神默认在首次可攻击后最早 30 秒开爆发，并等待实际落地；这个时间可以改，不是所有队伍都必须照着打。

火神柱子阶段默认留长 CD。刺羽、柱子、石牢、炸弹等机制目标，如果你没有主动选中，插件会尽量避免用群攻波及它们。**需要打哪一个仍然要自己选，不能靠插件决定机制顺序。** 浮游炮阶段也不能代替队伍要求的 LB。

Boss 消失时停火，回来后根据剩余 CD 和资源继续安排。预测也可能出错，尤其是中途启动、队伍打得特别快或跳了阶段时。更多细节见[绝神兵方案说明](1.1绝神兵自检与逻辑说明.md)。

## 目前还要注意什么

本地编译是 0 警告、0 错误，自动检查通过 **3167 项**，原有 **160 次、每次 300 秒**的循环模拟也已完成。[测试输出](verification/test-results-1.1.1.txt)保留在仓库里。

这些测试不能代替实战。模拟没有完整算装备、队伍团辅、自动攻击和网络延迟，也没有模拟这次首药提前后的实际开怪过程，所以不能把模拟威力直接当成 FFLogs DPS，更不能据此保证涨多少伤害。

群攻范围、目标移动、技能是否真正命中，以及特殊上天阶段 DoT 是否继续跳伤害，都还需要游戏里核对。短命羽毛和浮游炮暂按约 10 秒存活来估算，实际死得更快时可能算偏。

遇到不对劲的情况，先停止，点“复制最近执行诊断”，记下副本、阶段、目标和出问题的技能。不要带着异常继续让它跑。

## 编译与资料

项目使用 .NET 10 和 Dalamud API 15。编译需要对应版本的 Dalamud 开发环境。

```powershell
dotnet build BardPerfectLoopControl.csproj -c Release
dotnet run --project tests/BardPerfectLoopControl.Smoke -c Release -- --simulate
```

职业规则参考 [FFXIV 官方技能说明](https://na.finalfantasyxiv.com/jobguide/bard/)和 [The Balance](https://www.thebalanceffxiv.com/jobs/ranged/bard/basic-guide/)。绝神兵部分参考 [NAUR](https://naurffxiv.com/ultimate/uwu)、[Cactbot 时间轴](https://github.com/quisquous/cactbot/blob/main/ui/raidboss/data/04-sb/ultimate/ultima_weapon_ultimate.txt)和 [BossMod](https://github.com/awgil/ffxiv_bossmod/blob/master/BossMod/Modules/Stormblood/Ultimate/UWU/UWUEnums.cs)。药效计算参考 [Xivgear](https://github.com/xiv-gear-planner/gear-planner/blob/main/packages/xivmath/src/xivmath.ts)。
